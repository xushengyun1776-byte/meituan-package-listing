# 控件选择器速查表

> 项目：`meituan-套餐上架-2026-10-29`
> 用途：改脚本 / 排查「元素找不到」时，直接查这里的选择器。
>
> ⚠️ 前提：所有选择器都遵守两条铁律
> 1. **要带 `contextId`** —— 美团后台是多层 iframe，JS 必须在正确的 context 里跑。
> 2. **返回字符串，别返回 DOM 元素** —— `returnByValue=True` 会报
>    `Object reference chain is too long`。

## 一、上下文（context）定位

| 目标 | 判据 | 说明 |
|---|---|---|
| 顶层 frame | URL 含 `#/gw/static_resource/product#/listView` | 商品列表页 |
| 表单 iframe | 文本含「套餐名称」 | 新建/编辑套餐表单 |
| 商品选择弹窗 iframe | URL 含 `selectProduct` 或 `selectGoods` **且** 分组树条目数 > 0 | 见坑 14：可能有多个，选树最全的 |
| 「上传图片」裁剪弹窗 | 存在 `div.cropper-body` 且 **`offsetWidth > 0`** | ⚠️ 不能用 `getBoundingClientRect().width`（transform scale(0) 时恒为 0） |

```python
# 表单
form = [x for x in cdp.contexts() if "套餐名称" in x["text"]][0]

# 裁剪弹窗（注意用 offsetWidth）
probe = ("(()=>{const d=document.querySelector('div.cropper-body');"
         "return d && d.offsetWidth>0 ? 'YES' : '';})()")
```

## 三、规格组

### 组卡片结构

```
div[class*=group-header] / div[class*=group-wrap-item]   ← 组卡片容器
  ├─ 组名输入框     input.groupName_*
  ├─ 组类型下拉     「固定商品」/「可选商品」
  ├─ 「+ 添加商品」  ← 打开商品选择弹窗
  └─ 已选商品行     商品名 / 价格 / 加价 / 移除
```

### 组类型的**真值**在 React fiber 里

```javascript
const k = Object.keys(el).find(x => x.startsWith('__reactFiber'));
let f = el[k], d = 0;
while (f && d < 12) {
  const p = f.memoizedProps || {};
  if (p && p.groupName !== undefined && p.groupType !== undefined) {
    // p.groupType: 0 = 固定商品, 1 = 可选商品
    break;
  }
  f = f.return; d++;
}
```

> `input.value` 显示**滞后**，别拿它当判定依据。

### 「选 N」输入框

| 控件 | 判据 |
|---|---|
| 选 N 数量框 | 组卡片内、标签文本为「选」/「选N」的相邻 `input` |
| 必选/可选 | 文本 `必选` / `可选` 的 radio 叶子节点 |

## 四、商品选择弹窗（独立 iframe）

```
┌───────────────┬──────────────────────┬──────────────┐
│ 分组树         │ 商品列表             │ 已选区        │
│ x < 205       │ 205 ~ 625            │ x >= 625     │
│ div[class*=   │ 商品卡片              │ 已选商品      │
│  tag-list-item]│                      │              │
└───────────────┴──────────────────────┴──────────────┘
```

| 控件 | 选择器 |
|---|---|
| 分组树条目 | `div[class*=tag-list-item]`，取其内部 `div[class*=content]` 的 innerText |
| 分组树分组名（JS 常量） | `pick.JS_GROUP_NAMES` |
| 商品勾选框 | 商品名所在卡片内的 `span.custom-checkbox`（或 `input[type=checkbox]`） |
| 已选商品 | 右侧区域「已选商品 N」 |
| 「清空」按钮 | 文本 `清空` |
| 二次确认「确 定」 | `/^(确\s*定\|确定)$/`（**中间半角空格**） |

### ⚠️ 弹窗内搜索框**不可用**

不要尝试往搜索框打字检索。必须**走分组树导航**：

```python
groups = find_groups_for(md, items)   # 扫树，建立 {商品名: 分组名}
for name, group in groups.items():
    md.click(group_node(group))        # 点分组
    md.click(item_checkbox(name))      # 点该分组下的商品勾选框
```

## 五、上传图片裁剪弹窗

| 控件 | 选择器 | 说明 |
|---|---|---|
| 弹窗容器 | `div.roo-modal` | ⚠️ 离场后节点**不删除**（opacity=0 但铺满全屏） |
| 弹窗内容 | `div.cropper-body` | 判开放用 `offsetWidth>0` |
| Tab 切换 | 叶子节点文本 `本地上传` / `套餐拼图推荐` / `美团在线图库` / `智能生成` | |
| file input | **第一个** `input.cropper-upload__upload__input` | 页面上有 4 个（4 个 tab 各一），只有第一个有效 |
| 裁剪画布 | `div.cropper-container img` / `.cropper-canvas img` | 判成功用 `naturalWidth > 0` |
| 「保存图片」按钮 | `button` 文本 `保存图片` | ⚠️ button 自身 `pointer-events:none`，**点内部 span** |
| 「重新上传」 | 同区域 footer | |
| 「上传本地图片」按钮 | 文本 `上传本地图片` | 是视觉按钮，真正 input 在它后面 |

### 关键顺序（照抄即可跑通）

```python
cdp.wake()                       # ① 唤醒页面（否则弹窗卡在入场第 0 帧）
click_el(cdp, fid, SEL_SLOT)     # ② 点主图上传槽位
cdp.finish_animations(fid)       # ③ 把入场动画推到终态
cdp.js_click(fid, SEL_TAB_LOCAL) # ④ 切「本地上传」
cdp.send("DOM.setFileInputFiles", nodeId=nid, files=[path])   # ⑤ 设文件
wait_img_loaded(cdp, fid)        # ⑥ 等 naturalWidth > 0
cdp.js_click(fid, SEL_SAVE_SPAN) # ⑦ 点「保存图片」内部 span
purge_modals(cdp, fid)           # ⑧ 清掉离场残留遮罩
```

### 删除用合成事件（不要用坐标点击）

```javascript
const li = [...document.querySelectorAll('ul[class*=thumbnailList] > li')]
    .filter(t => !String(t.className).includes('upload'))[0];
const c = li.querySelector('img[class*=closeIcon]');
c.dispatchEvent(new MouseEvent('click', {bubbles:true, cancelable:true, view:window}));
```

> 坐标点击会被 hover 弹出的 `roo-tooltip` 挡住（见坑 12）。

## 九、通用 JS 片段（可直接复用）

### 取「可见且可点」的按钮（推荐判定，比「容器宽度>0」可靠）

```javascript
(()=>{
  const b = [...document.querySelectorAll('button')]
      .filter(e => (e.innerText||'').trim() === '保存图片');
  if (!b.length) return null;
  const bt = b[b.length-1];
  const r = bt.getBoundingClientRect();
  if (r.width <= 0) return null;          // 被 transform 缩放为 0 → 视为不可用
  const hit = document.elementFromPoint(r.x + r.width/2, r.y + r.height/2);
  return hit ? bt.querySelector('span') || bt : null;
})()
```

### 读 React fiber 里的组类型

见上文「三、规格组」。

### 统计某个 context 里的分组树条目数（用来挑对弹窗 iframe）

```javascript
(()=>{
  const a = [...document.querySelectorAll('div[class*=tag-list-item]')]
      .map(e => { const c = e.querySelector('div[class*=content]');
                  return c ? (c.innerText||'').trim() : ''; })
      .filter(Boolean);
  return a.length;
})()
```

> ⚠️ `.filter()` 必须作用在 `.map()` 的**结果数组**上。
> 写成 `{...}.filter(Boolean)` 是运行时错误 ——
> 而 `Runtime.evaluate` 会**静默**把它变成 `None`（见坑 5）。

## 十、失效了怎么办（自查顺序）

```
1. 元素不在？
   → 先 wake() + finish_animations()，再看 offsetWidth
   → 用 evaluate(strict=True) 拿到真实 JS 错误，别猜选择器
2. 元素在但点不动？
   → 是不是 <button>？改点内部 span
   → 是不是视口外？先 scrollIntoView 并等 0.7s
   → 是不是有残留遮罩？purge_modals() 再试
   → 是不是在另一个 context？contexts() 里逐个查
3. 点了但业务没变？
   → 读 React fiber（不是 input.value）
   → 确认 iframe 被重建导致 contextId 失效（Cannot find context with specified id）
```
